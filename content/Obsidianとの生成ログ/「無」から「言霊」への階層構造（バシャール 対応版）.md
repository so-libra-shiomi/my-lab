### 「無」から「言霊」への階層構造（バシャール 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | バシャール                                           |
| --------- | --------- | -------------------------------------- | ----------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | 現実は固定された一枚岩ではないという認識の根源 [^1]。                   |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | 並行現実（パラレルリアリティ）としての可能性の重ね合わせの場 [^2]。            |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | 信念体系が知覚と行動の範囲を決め、選択が現実を分岐させる振る舞い [^3]。          |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | バシャール構文を思考モデルとして捉え、核を抽出する認知の枠組み [^4]。           |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | 結果への期待や信念の固定を手放し、因果回路を切る操作 [^5]。                |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | 祓い後に残る、干渉が少なく身体が動ける「ワクワク」という微細な傾きを指針とする安定 [^6]。 |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | 因果を固定せず、分からないままの可能性に開かれた中間の立ち位置 [^7]。           |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | 配置が整った後、因果を固定せずに最小限の介入で選択・行動を促す言葉 [^8]。         |
