### 「無」から「言霊」への階層構造（カオス理論 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | カオス理論                                                       |
| :-------- | :-------- | :------------------------------------- | :---------------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | 決定論的ルールそのもの。特定の初期値が与えられる前の、抽象的な系の法則。                        |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | **アトラクタ**。系が取りうる状態の範囲。無秩序ではなく、振る舞いが収まる領域 [^1]。              |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **初期値鋭敏性**。最初の僅かな違いが、時間を経て全く別の結果を生む振る舞い [^2]。               |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | **初期条件の設定**。系の振る舞いを一意に定めるための、最初の状態を定義する行為 [^3]。             |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | **制御を手放すこと**。特定の変数を固定しようとする介入をやめ、系の自由度を奪わない操作 [^4]。         |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | **自律的振る舞いの許容**。外部からの介入を止め、系が自らのアトラクタに沿って自然に振る舞うのを待つこと [^5]。 |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | **分岐点**。ごく小さな入力で、系の振る舞いが質的に大きく変化する臨界点に留まること [^6]。           |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | **微小入力**。分岐点において、系全体の振る舞いを変化させるための、最小限の介入 [^7]。             |
