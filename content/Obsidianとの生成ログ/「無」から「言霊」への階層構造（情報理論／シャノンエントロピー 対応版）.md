### 「無」から「言霊」への階層構造（情報理論／シャノンエントロピー 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | 情報理論／シャノンエントロピー                                                  |
| :-------- | :-------- | :------------------------------------- | :--------------------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | **最大エントロピー状態**。事前確率が等しく、予測不能性が最大な状態 [^1]。                        |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | **高エントロピー状態**。「何が来るか分からない」選択肢が多く、不確かさが高い状態 [^2]。                 |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **自発的なエントロピーの減少**。高エントロピー状態から、ゆらぎによって自然に偏りが生じ、意味が立ち上がるプロセス [^3]。 |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | **測定のための「与えられた制約」**。エントロピーを定義・測定可能にするための、状態空間（系の範囲）の設定 [^4]。     |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | **確率分布の偏りを除去する操作**。意図や期待といったバイアスを落とし、エントロピーを最大化する行為 [^5]。        |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | **高エントロピー状態の保持**。確率が再び歪むのを防ぎ、「分からなさ」に留まる安定性 [^6]。                |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | **自発的破れが起きる直前の最大エントロピー状態**。未来が読めず、次の行動が決まらない臨界点 [^7]。            |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | **自発的に生じた偏りを固定しない最小限の介入**。高エントロピー状態からの自発的破れに、弱い方向性を与える情報 [^8]。   |
