### 「無」から「言霊」への階層構造（禅 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | 禅との対応                                                                |
| --------- | --------- | -------------------------------------- | -------------------------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | **概念停止の刃**。「ある／ない」という二元的な掴みを断ち切り、問いそのものを消滅させるための言葉であり、実践[^1]。        |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | **関係性の観察**。「それ単独では成立していない」という世界の成り立ち方（縁起）を観る視点そのもの[^1]。              |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **一時的な成り立ち**。あらゆる事象が「縁」によって一時的に成り立っているという、「空」が示す世界の動的なあり方[^1]。       |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | **坐禅の実践**。問いや判断から距離を置き、ただ観察するための「場」を身体と時間の中に設定する行為。（※ノート内の直接記述なし）    |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | **掴みを外す所作**。「治そう」「分かろう」といった意図や判断を手放し、思考の付着物を払い落とすこと[^1]。             |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | **沈黙と待つ姿勢**。問いに対して安易に答えず、答えが成立しない場に留まることで、問い自体が静まるのを待つこと[^1]。        |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | **只管打坐（しかんたざ）**。何かを求めるのではなく、ただ「今ここ」の身体感覚や呼吸に立ち返り続ける実践。（※ノート内の直接記述なし） |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | **公案**。「無」の一字のように、理解のためでなく、思考の固定化を断ち切る「刃」として機能する言葉[^1]。              |
