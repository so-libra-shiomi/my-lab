### 「無」から「言霊」への階層構造（対称性の自発的破れ 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | 対称性の自発的破れとの対応                                                               |
| --------- | --------- | -------------------------------------- | --------------------------------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | **完全な対称性**。世界のルールが偏っておらず、「何も区別のない世界」が先に在る状態[^1]。                            |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | **等価な真空の連続体**。どの方向にも倒れる可能性があり、理論上は等価な基底状態が無限に存在する場[^2]。                     |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **対称性の自発的破れ**。法則は対称なまま、ほんの僅かな「ゆらぎ」をきっかけに、現実の状態が一方向を選んでしまう出来事[^1]。           |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | **物理系の設定**。ペンを立てる机や、観測対象となる宇宙領域など、破れが起こるための「与えられた制約」そのもの[^3]。               |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | **法則の対称性の確認**。結果（例：東に倒れた）から原因を逆算せず、「物理法則はどの方向も選んでいない」という偏りのない状態に立ち返ること[^1]。 |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | **真の真空への落下**。破れが起きた後、系がエネルギー的に最も低く、それ以上動かない安定状態（基底状態）に落ち着くこと[^2]。           |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | **偽の真空（対称な状態）**。ペンが倒れる直前のように、対称だがエネルギー的に不安定で、まだどちらに破れるか決まっていない瞬間[^2]。       |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | **ゆらぎ／ゴールドストーン粒子**。破れを起こすきっかけであり、破れた後に「選ばれなかった可能性の名残」として残る“自由度”や“感触”[^4]。   |
