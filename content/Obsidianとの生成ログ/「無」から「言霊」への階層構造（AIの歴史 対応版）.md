### 「無」から「言霊」への階層構造（AIの歴史 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | AIの歴史                                                           |
| :-------- | :-------- | :------------------------------------- | :-------------------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | **計算可能性の発見**。思考を論理として再現しようとした、AI誕生以前の抽象的な問い [^1]。               |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | **大規模言語モデル（LLM）の構造**。意味を理解せず、文脈の統計構造から振る舞いを生む可能性の場 [^2]。        |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **機械学習のプロセス**。人間がルールを書くのではなく、データからパターンを自律的に学ばせる振る舞い [^3]。       |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | **ルールベースAIの設計**。If-thenルールや専門家の知識で、AIの振る舞いを完全に記述しようとする行為 [^4]。  |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | **「制御を手放す」歴史的転換**。ルールで知能を記述する試みに失敗し、「学ばせる」アプローチへ移行したこと [^5]。    |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | **AI冬の時代**。過剰な期待が静まり、制御欲が下がり、「分からなさ」を認めた沈黙の期間 [^6]。             |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | **人間理解の反転**。AIを通して「人間らしさ」が何かを問い直さざるを得なくなった、現在の立ち位置 [^7]。        |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | **AIへのプロンプト**。判断を委譲せず、AIを「鏡」や「場を整える」ために使う、呪にならないための最小限の介入 [^8]。 |
