### 「無」から「言霊」への階層構造（潜在意識・願望実現 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | 潜在意識・願望実現との対応                                                     |
| --------- | --------- | -------------------------------------- | ----------------------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | **未分化な意識の源泉**。願望や恐れがまだ「言葉」や「形」になる前の、純粋な可能性の状態。                    |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | **可能性の場としての潜在意識**。「まだ決まっていない」選択肢が無限に広がる高エントロピーな領域[1]。             |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **信念が現実を生成するプロセス**。内部の信念パターン（関係性）が、現実の出来事として立ち現れること[1]。           |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | **意識的な「信じる」という行為**。注意や信念を特定の方向に定めることで、潜在意識が働くための「場」を限定する[1]。      |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | **潜在意識のブロック解除**。不要な思い込みや緊張（不自然な低エントロピー）を解放し、変化が起きやすい状態に戻す[1]。     |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | **「揺らいでも壊れない」という身体感覚**。不確定な状態（高エントロピー）を恐れず、変化が起きるのを待てる安定した状態[1]。  |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | **「すでに叶った」感覚**。未来の結果を待つのではなく、「今ここ」で完了しているという状態に留まること[2]。          |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | **アファメーションや意図の設定**。結果を固定せず「整う方向へ」とだけ方向付けし、潜在意識の自己組織化を促す最小限の合図[1]。 |
