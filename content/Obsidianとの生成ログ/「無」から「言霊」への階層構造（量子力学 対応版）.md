### 「無」から「言霊」への階層構造（量子力学 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | 量子力学                               |
| :-------- | :-------- | :------------------------------------- | :--------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | 性質が未確定な未観測状態。 [^1]                 |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | 関係性の中でのみ性質が確定すること。 [^2]            |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | 相互作用によって現象が立ち上がること。 [^3]           |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | 観測行為そのもの（系と環境の区別）。 [^4]            |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | 過剰な観測を減らし、重ね合わせを許すこと。 [^5]         |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | デコヒーレンスを避け、重ね合わせ状態を保つこと。 [^6]      |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | 可能性が重なり合った未確定な状態（重ね合わせ）。 [^7]      |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | 重ね合わせを一つの結果に収縮させる最小の相互作用（観測）。 [^8] |
