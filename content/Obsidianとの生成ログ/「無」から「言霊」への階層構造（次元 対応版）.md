### 「無」から「言霊」への階層構造（次元 対応版）

| 層（階層）     | キーワード     | 役割・定義                                  | 次元                                                 |
| --------- | --------- | -------------------------------------- | -------------------------------------------------- |
| **世界の基底** | 無 (む)     | 固定された実体や意味が立っていない、区別以前の状態。             | 次元が成立する以前の、記述の軸も自由度もない根源的な状態。                      |
|           | 空 (くう)    | 関係性が起こりうるが、何も確定していない可能性の場。             | 自由度が多く、因果が唯一でない可能性の場 [^1]。                         |
|           | 縁起 (えんぎ)  | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | 因果が唯一ではなく、複数の記述可能性が編まれる世界の振る舞い [^1]。               |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。        | 世界を特定の記述軸（次元）で切り分け、立ち位置を定める行為 [^1]。                |
| **結界の調整** | 祓い (はらい)  | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。          | 拘束された次元固定を解除し、因果を一旦無効化する操作 [^1]。                   |
|           | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。              | 解除された次元固定が再び起きないよう、未選択の状態を静かに保つプロセス [^1]。          |
| **立ち位置**  | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。              | 全ての次元が重なり、まだ何も選ばれていない、次元が成立しない状態 [^1]。             |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。   | 次元を一時的に固定しつつ、その固定が仮であることを示し、自由な立ち位置へ導く最小限の言葉 [^1]。 |
