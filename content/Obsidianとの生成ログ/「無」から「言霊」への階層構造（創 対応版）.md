### 「無」から「言霊」への階層構造（創 対応版）

| 層（階層） | キーワード | 役割・定義 | 創との対応 |
|---|---|---|---|
| **世界の基底** | 無 (む) | 固定された実体や意味が立っていない、区別以前の状態。 | **創造が起こる前の余白**。「創」は足す行為ではなく、「引く・空ける」ことで生まれる「間（ま）」や「虚」を扱う[^1]。 |
| | 空 (くう) | 関係性が起こりうるが、何も確定していない可能性の場。 | **内なる可能性の倉**。「創」はゼロからではなく、内側に蓄えられた未知の可能性（倉）から切り出される[^1]。 |
| | 縁起 (えんぎ) | 無と空を土台に、関係性が編まれ現象が立ち上がり続ける世界の振る舞いそのもの。 | **非線形な立ち現れ**。「創」は努力量に比例せず、長い停滞の後に一気に進むなど、複雑系の振る舞いとして現れる[^1]。 |
| **人間の接点** | 結界 (けっかい) | 縁起の流れの中に、人間が立つための仮の輪郭・位置を区切る行為。 | **切れ目を入れる行為**。「創」は「刀」で切れ目を入れることであり、その区切りによって初めて流れや循環が生まれる[^1]。 |
| **結界の調整** | 祓い (はらい) | 結界内に生じた固定化（単純因果、物語化など）を落とす操作。 | **作らないことを選ぶ力**。「何を作らないかを選ぶ力」や「言語化しすぎない勇気」として、過剰なものを削ぎ落とす[^1]。 |
| | 鎮魂 (ちんこん) | 祓われた後の結界を静かに保ち、安定させるプロセス。 | **創造後の身体への着地**。「創った後」に呼吸が深くなり、身体感覚が戻るプロセス。創る前の内圧の高まりを鎮める[^1]。 |
| **立ち位置** | 中今 (なかいま) | 縁起が固定される直前の瞬間に立ち続ける姿勢・態度。 | **「起こる」のを待つ姿勢**。創造は管理できず、「する」より「起こる」もの。その瞬間を待つ、静かで覚悟のある態度[^1]。 |
| **最小の介入** | 言霊 (ことだま) | 中今に立ったまま、縁起の流れを固定せずにそっと向きを与える最小限の言葉。 | **内なるものを切り出す一太刀**。「創」の「刀」のように、最小限の介入で本質を切り出し、形を与える行為[^1]。 |
